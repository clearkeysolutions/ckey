## What it checks

At a fixed 2-inch print size, denser versions need a closer, steadier camera; version 10 still reads.

## Why

More data means smaller marks at the same size. This shows where, for an ordinary phone, a code should be printed larger to carry more.

## Set up

1. Print the test sheet at 100% scale; each code is 2.0 inches wide.
2. Use ordinary indoor light.

## Steps

1. Try each code, A (version 1) to E (version 20), from about 20 cm, moving closer if needed.
2. Allow up to 8 seconds each.
3. Record whether it read and the closest distance you needed.

## What to record

- **Read within 8 seconds**, boolean, required. For each of: v1, v5, v10, v15, v20.
- **Distance needed** (cm), number, optional. For each of: v1, v5, v10, v15, v20.

Every report also records the device, operating system, reader and its version, and the printer or screen.

## How to grade it

- **Pass:** Versions 1, 5 and 10 read.
- **Partial:** Versions 1 and 5 read but not 10.
- **Fail:** Version 5 did not read.
