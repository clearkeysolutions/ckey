## What it checks

The print layout (Profile 0.1) reads at smaller sizes than the standard layout.

## Why

The print layout uses larger marks and gaps for small labels, so a printer's dot gain and a camera's blur do not close the gaps. This checks that it earns its place.

## Set up

1. Print the test sheet at 100% scale on the best printer you have, ideally 600 dpi.
2. Codes A to C use the standard layout; D to F use the print layout, at the same three sizes.

## Steps

1. From as close as your phone can focus, try each code for up to 8 seconds.
2. Record whether it read.

## What to record

- **Read within 8 seconds**, boolean, required. For each of: A std 0.3 in, B std 0.4 in, C std 0.5 in, D print 0.3 in, E print 0.4 in, F print 0.5 in.
- **Printer resolution** (dpi), number, optional.

Every report also records the device, operating system, reader and its version, and the printer or screen.

## How to grade it

- **Pass:** A print-layout code read at a size where the standard layout did not.
- **Partial:** Both layouts read at the same sizes.
- **Fail:** The print layout read at no size where the standard layout read.
