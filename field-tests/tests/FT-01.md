# FT-01: Smallest printed size

## What it checks

A standard-layout CKey holding a short link reads when printed at 1 inch (25 mm) wide.

## Why

Print size is the first thing a designer chooses and the easiest mistake to make. The core's certification models camera photos down to a few pixels per module; this test checks that model against real printers and real cameras.

## Set up

1. Print the test sheet at 100% scale (no "fit to page") on plain white paper.
2. Measure code F with a ruler: it must be 2.0 inches (51 mm) wide. If it is not, your printer scaled the sheet; fix the print settings and print again.
3. Hold the phone about 20 cm from the sheet in ordinary indoor light.

## Steps

1. Open the reader.
2. Point it at each code from A (smallest) to F (largest), one at a time, for up to 5 seconds each.
3. Record whether it read and roughly how many seconds it took.

## What to record

- **Read within 5 seconds**, boolean, required. For each of: A, B, C, D, E, F.
- **Seconds to read** (s), number, optional. For each of: A, B, C, D, E, F.

Every report also records the device, operating system, reader and its version, and the printer or screen.

## How to grade it

- **Pass:** Code D (1 inch) and every larger code read.
- **Partial:** Only code E (1.5 inches) or larger read.
- **Fail:** Code F (2 inches) did not read.
