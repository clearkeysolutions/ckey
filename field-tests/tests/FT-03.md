## What it checks

A CKey reads when seen at up to 45 degrees off square.

## Why

People rarely hold a phone square to a label. The frame and four corner finders exist to undo perspective; this checks how far they stretch.

## Test codes

Print or open the sheet at [https://openckey.org/tests/sheet?id=FT-03](https://openckey.org/tests/sheet?id=FT-03). It is drawn by the CKey web SDK from the values below.

## Set up

1. Print the test sheet at 100% scale; the code is 2.0 inches wide.
2. Lay it flat on a table in even light.
3. Hold the phone about 30 cm away.

## Steps

1. Start square above the code (0 degrees), then tilt the phone to roughly 30, 45, 60 and 70 degrees from straight down, keeping the code centred.
2. Allow up to 5 seconds at each angle.
3. Record whether it read. A protractor app helps but an estimate is fine.

## What to record

- **Read within 5 seconds**, boolean, required. For each of: 0°, 30°, 45°, 60°, 70°.

Every report also records the device, operating system, reader and its version, and the printer or screen.

## How to grade it

- **Pass:** It read at 0, 30 and 45 degrees.
- **Partial:** It read at 0 and 30 degrees but not at 45.
- **Fail:** It did not read at 30 degrees.
