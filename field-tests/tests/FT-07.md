## What it checks

A style the core certifies reads in practice, and reads about as well as plain black on white.

## Why

Certification photographs each style in a model before it is allowed. This is the check that the model's verdict holds on real paper and real cameras, style by style.

## Set up

1. Print the test sheet in colour at 100% scale; each code is 1.5 inches wide.
2. Use ordinary indoor light and hold the phone about 20 cm away.

## Steps

1. Try each code, A to E, for up to 5 seconds.
2. Record whether it read and roughly how many seconds it took.
3. Note anything about a style that seemed harder, such as needing to move closer.

## What to record

- **Read within 5 seconds**, boolean, required. For each of: A plain, B concept, C dark, D accents, E dots.
- **Seconds to read** (s), number, optional. For each of: A plain, B concept, C dark, D accents, E dots.

Every report also records the device, operating system, reader and its version, and the printer or screen.

## How to grade it

- **Pass:** Every style read.
- **Partial:** The plain code and at least three styles read.
- **Fail:** The plain code read but two or more styles did not.
