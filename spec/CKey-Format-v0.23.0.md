# CKey Format v0.23.0 — Profile 2 Finder Moat and Polar Join

Profile 2 reserves a `3.75`-unit radial moat only in the actual outer
quadrant of each finder, so Cartesian modules cannot touch finder caps while
the corner is not a square dead zone. Cartesian payload begins outside radius
`9.6`, leaving a measured separation after the radial alphabet.

Encoders emit format byte `0x17` (decimal 23), profile byte `0x02`.
